# Anime Downloader Bot

ربات تلگرام دانلود انیمه (ساب/داب) روی GitHub Actions.

## تنظیمات
- Secret: `BOT_TOKEN`
- Variable: `OWNER_ID` (آیدی عددی خودت)، `MAX_HEIGHT` (پیش‌فرض 720)

## نحوه کار
AniList برای جستجو → MegaPlay (کتابخانه انیمه‌کوتو) و WCO برای استریم →
yt-dlp/ffmpeg برای دانلود و تقسیم → ارسال به تلگرام.

## نکته‌ها
- هر اجرا ~۵.۵ ساعت کار می‌کند و با cron هر ۶ ساعت ری‌استارت می‌شود.
- فایل‌ها روی دیسک موقت رانر هستند و بعد از ارسال پاک می‌شوند.
